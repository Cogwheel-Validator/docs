# Usefull commands for Celestia

## 🔑 Key management

<Callout type="info" text={`Change wallet in the commands to your own wallet name.`} />

#### Add new key

```bash
celestia-appd keys add wallet
```

#### Recover existing key

```bash
celestia-appd keys add wallet --recover
```

#### List all keys

```bash
celestia-appd keys list
```

#### Delete key

```bash
celestia-appd keys delete wallet
```

#### Export key to the file

```bash
celestia-appd keys export wallet
```

#### Import key from the file

```bash
celestia-appd keys import wallet wallet.backup
```

#### Query wallet balance

```bash
celestia-appd q bank balances $( celestia-appd keys show wallet -a)
```

## 🧙 Validator management

<Callout type="info" text={`Make sure to change values for moniker, identity, details website to your own values.`} />

#### Edit existing validator

When editing a validator, you can use the following command. But you do not need to edit all the fields. 
You can edit only the fields you want to change. The gas flags are required for the command to work.
```bash
celestia-appd tx staking edit-validator \
--new-monike "YOUR_MONIKER_NAME" \
--identity "YOUR_KEYBASE_ID" \
--details "YOUR_DETAILS" \
--website "YOUR_WEBSITE_URL" \
--chain-id celestia \
--commission-rate "0.05" \
--gas-adjustment 1.5 \
--gas auto \
--gas-prices "" \
--from wallet
```

```bash
celestia-appd tx staking edit-validator /path/to/validator.json --gas-adjustment 1.5 --gas auto
 --gas-prices  -y
```

#### Unjail validator

```bash
celestia-appd tx slashing unjail --from wallet --chain-id celestia --gas-adjustment 1.5 --gas auto
 --gas-prices  -y
```

#### Jail reason

```bash
```bash
celestia-appd query slashing signing-info $( celestia-appd comet show-validator)
```

#### List all active validators

```bash
celestia-appd q staking validators -oj --limit=3000 | jq '.validators[] | select(.status=="BOND_STATUS_BONDED")' | jq -r '(.tokens|tonumber/pow(10; 6)|floor|tostring) + " \t " + .description.moniker' | sort -gr | nl
```

#### List all inactive validators

```bash
celestia-appd q staking validators -oj --limit=3000 | jq '.validators[] | select(.status=="BOND_STATUS_UNBONDED")' | jq -r '(.tokens|tonumber/pow(10; 6)|floor|tostring) + " \t " + .description.moniker' | sort -gr | nl
```

#### View validator details

```bash
celestia-appd q staking validator $( celestia-appd keys show wallet --bech val -a)
```

## 🪙 Token management

#### Withdraw rewards from all validators

```bash
celestia-appd tx distribution withdraw-all-rewards --from wallet --chain-id celestia --gas-adjustment 1.5 --gas auto --gas-prices  -y
```

#### Withdraw commission and rewards from your validator

```bash
celestia-appd tx distribution withdraw-rewards $( celestia-appd keys show wallet --bech val -a) --commission --from wallet --chain-id celestia --gas-adjustment 1.5 --gas auto --gas-prices  -y
```

#### Delegate tokens to yourself

```bash
celestia-appd tx staking delegate $( celestia-appd keys show wallet --bech val -a) 100000000000 --from wallet --chain-id celestia --gas-adjustment 1.5 --gas auto --gas-prices  -y
```

#### Delegate tokens to validator

```bash
celestia-appd tx staking delegate <TO_VALOPER_ADDRESS> 100000000000 --from wallet --chain-id celestia --gas-adjustment 1.5 --gas auto --gas-prices   -y
```

#### Redelegate tokens to another validator

```bash
celestia-appd tx staking redelegate $( celestia-appd keys show wallet --bech val -a) <TO_VALOPER_ADDRESS> 1000000$ublit --from wallet --chain-id celestia --gas-adjustment 1.5 --gas auto --gas-prices  -y
```

#### Unbond tokens from your validator

```bash
celestia-appd tx staking unbond $( celestia-appd keys show wallet --bech val -a) 1000000$ublit --from wallet --chain-id celestia --gas-adjustment 1.5 --gas auto --gas-prices  -y
```

#### Send tokens to the wallet

```bash
celestia-appd tx bank send wallet <TO_WALLET_ADDRESS> 1000000$ublit --from wallet --chain-id celestia --gas-adjustment 1.5 --gas auto --gas-prices  -y
```

## 🏛️ Governance

## ⚡️ Utility

#### Update Indexer

**Disable indexer**

```bash
sed -i -e 's|^indexer *=.*|indexer = "null"|' $HOME/.celestia-app/config/config.toml
```

**Enable indexer**

```bash
sed -i -e 's|^indexer *=.*|indexer = "kv"|' $HOME/.celestia-app/config/config.toml
```

#### Update pruning

```bash
sed -i \
  -e 's|^pruning *=.*|pruning = "custom"|' \
  -e 's|^pruning-keep-recent *=.*|pruning-keep-recent = "2000"|' \
  -e 's|^pruning-interval *=.*|pruning-interval = "100"|' \
  $HOME/.celestia-app/config/app.toml
```

## 🔧 Maintenance

#### Get validator info

```bash
celestia-appd status 2>&1 | jq .ValidatorInfo
```

#### Get sync info

```bash
celestia-appd status 2>&1 | jq .SyncInfo
```

#### Enable prometheus

```bash
sed -i -e "s/prometheus = false/prometheus = true/" $HOME/.blit/config/config.toml
```

#### Reset chain data

```bash
celestia-appd tendermint unsafe-reset-all --keep-addr-book --home $HOME/.blit --keep-addr-book
```

#### Remove node



<Callout type="error" emoji="☢️">
  Make sure you have backed up your priv_validator_key.json!
</Callout>

```bash
cd $HOME
sudo systemctl stop celestia-appd
sudo systemctl disable celestia-appd
sudo rm /etc/systemd/system/celestia-appd.service
sudo systemctl daemon-reload
rm -f $(which celestia-appd)
rm -rf $HOME/.blit
rm -rf $HOME/blitchain
```
